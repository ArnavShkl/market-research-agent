# Market Research Agent

An AI-powered competitive intelligence dashboard that turns a company, product, or market prompt into an executive-style strategy report.

## What It Does

- Generates a company-specific executive snapshot
- Maps real or closest competitor alternatives
- Identifies market gaps and opportunity plays
- Builds a target-company point of view
- Produces go-to-market moves, risk mitigations, KPIs, and a strategic verdict
- Supports Gemini, Ollama local AI, and an illustrative demo mode

## Tech Stack

- HTML
- CSS
- JavaScript
- Gemini API-ready
- Ollama local AI-ready
- Prompt engineering
- Structured JSON parsing

## Portfolio Description

Market Research Agent is a single-page AI strategy tool designed for founders, analysts, and product teams. It takes a target company or market and generates a boardroom-ready competitive intelligence report with positioning, named competitors, market gaps, opportunity plays, go-to-market moves, risks, KPIs, and an executive verdict.

## Notes

No private API key is hardcoded. Users can paste their own Gemini API key, run Ollama locally, or use Demo mode.
