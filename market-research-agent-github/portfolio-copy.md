# Portfolio Copy

## Project Title

Market Research Agent

## One-Line Description

An AI-powered competitive intelligence dashboard that generates company-specific market research reports from a single prompt.

## Short Case Study

I built Market Research Agent as a portfolio-ready AI strategy tool for founders, product teams, and analysts. The app takes a company, product, or market as input and produces a structured executive report with a target-specific point of view, competitive landscape, positioning analysis, market gaps, opportunity plays, go-to-market moves, risks, KPIs, and a strategic verdict.

The project focuses on practical AI product design: clear prompts, structured JSON output, fallback demo mode, user-provided API keys, local Ollama support, and a polished corporate dashboard interface.

## Features

- Company-specific market intelligence reports
- Named competitor analysis
- Target POV and strategic issue framing
- Market gaps and opportunity plays
- GTM plan, risks, mitigations, and KPIs
- Copy report and JSON export
- Gemini, Ollama, and demo provider modes
